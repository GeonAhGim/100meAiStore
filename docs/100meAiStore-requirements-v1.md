# 100meAiStore 확정 요구사항 v1

## 범위와 우선순위
- 현재 단계는 구현 금지. 구현 워커가 추가 질문 없이 분해할 수 있는 90% 이상 완성도의 아키텍처를 만든다.
- 국내 MVP 채널은 네이버 스마트스토어와 쿠팡이며 동시에 등록한다. 해외는 국내 모의 테스트 후 시장/API/물류/비용/반품/가입/마진 순으로 비교할 확장 파이프라인만 설계한다.
- 국내 직배송 위탁판매부터 시작한다. 공급처 API, CSV, Excel, XML, 수동 주문대행을 모두 어댑터로 수용한다.
- 상품군: 반려동물 생활용품, 국내 정식 유통 사료·간식, 국내 정식 유통 화장품, 비브랜드 패션잡화, 생활·트렌드 상품. 명품·고위험 규제품은 초기 제외한다.
- 수량 할당보다 예상 순이익을 우선한다. 후보 전체 약 300개, 승인 등록 약 50개를 양 채널에 동시 등록하되 기준 미달 상품을 억지로 채우지 않는다.

## 멀티테넌시와 권한
- 사용자는 여러 사업자 워크스페이스에 속할 수 있다. 사업자별 데이터·자격증명·비용을 완전히 격리한다.
- 사업자당 마스터 1명과 구성원 2명, 기본 최대 3명. 마스터가 자금/출납과 상품등록/CS 권한을 조정하며 두 권한을 함께 부여할 수 있다.
- 마스터만 사용자 추가·삭제, 사업자/채널 삭제, 한도·정책 변경 같은 중요 작업을 수행한다. 일반 승인에는 해당 권한을 가진 한 계정의 승인만 필요하다.
- 사업자 이전/분리/삭제 선택을 지원한다. 주문·정산 감사기록은 원 사업자에 보존하고 법정 보존기간 후 개인정보를 제거한다. 삭제는 복구기간을 둔다.
- 이메일 로그인, 무료 이메일 OTP 또는 TOTP 기반 2단계 인증. 권한 회수는 기존 세션에도 즉시 적용한다.

## 승인과 운영 일정
- 관리자 에이전트 기본 실행: 09:00, 13:00, 17:00, 21:00. 사용자가 변경 가능하다.
- 상품 승인함: 09:00, 13:00, 17:00. 발주 승인함: 09:00, 12:00, 15:00, 18:00. 사용자가 변경 가능하다. 겹치는 승인함은 분리한다.
- 모든 발주, 신규상품, 공급처 교체, 환불/보상, 비정형 CS, 판매중지, 콘텐츠 변경은 사용자 승인 대상이다. 승인 대기는 모두 24시간이며 임의 승인 시 즉시 처리한다.
- 공급가/재고/마진이 승인 후 바뀌면 재검사한다. 10% 미만 마진은 실행 차단한다.
- 품절/마이너스 마진/위험 시 판매를 즉시 임시중지하고 최종 조치는 승인받는다. 대체 공급처는 동일 바코드/모델/브랜드/규격/색상/구성일 때만 후보화하며 불명확하면 질문한다.
- 관리자 에이전트는 정보가 불충분하거나 의미가 여러 가지면 추론하지 않고 부족정보/영향/선택지/권장안/무응답 안전조치를 질문한다.
- 긴급 알림: 계정정지·보안사고, 대량품절, 마이너스마진, 발주마감, 개인정보 위험, 긴급정지. 중복주문은 일반 예외. 앱 푸시→5분 후 이메일·ChatGPT 재전송. 한 명 확인 시 전체에 반영한다.

## 자금과 수익
- 초기 현금 50만원, 발주 운전자금 약 300만원. 하루 사업자별 발주 원가 기본한도 200만원, 단일주문 10만원 경고, 안전잔액 50만원을 기본으로 UX에서 설정 가능하게 한다.
- 카드 자동결제와 계좌이체 자동실행은 없다. 사용자가 승인 후 공급처 결제하고 주문번호/실결제액/결제일/출고예정일/영수증 일부를 입력하거나 안전하게 자동 수집한다.
- 금융은 수동 장부 및 CSV/Excel 대사를 구현 대상으로 하고 조회형 금융 API 커넥터 경계만 둔다. 이체/결제 실행은 비활성화한다.
- 기본 수익 기준: 상품당 예상 순이익 3,000원 이상, 광고 제외 순마진 15% 이상, 광고 포함 10% 이상. 마스터가 설정 가능하다.
- 목표는 주 순이익 500만원이나 보장값이 아니라 검증 KPI다. 판매가-공급가-배송비-채널/결제 수수료-광고비-예상 반품비-AI/콘텐츠비로 계산한다.
- 초기 광고 실험비는 10만원 이하.

## 상품·콘텐츠·CS
- 공급처는 카테고리별로 분산해 총 4~10개 후보를 비교한다. 사업자정보와 반품주소 미확인 공급처는 강제 제외하고, 나머지는 신뢰등급과 경고로 승인 가능하게 한다.
- 이미지 사용권 불명확 상품도 경고 후 승인 요청하되 불법·명백한 상표권 침해는 시스템이 강제차단한다.
- 기본 이미지는 원본 보존, 리사이즈·배경제거·색감·텍스트 배치. 생성 배경은 선택 기능이며 제품 자체 사실을 왜곡하지 않는다. 품목별 정책으로 유연하게 적용한다.
- 영상은 판매/조회 기준을 넘거나 필요성이 높은 상품만 제안하고, 권리 확인된 자산만 사용한다. 후보 콘텐츠는 10일 보관, 등록/보관표시 콘텐츠와 버전 이력은 유지한다.
- AI CS 초안은 사용자가 편집·승인한다. 주문접수, 배송조회, 영업시간, 반품절차/주소, 품절 예정, 접수확인은 정형 자동답변 가능. 환불 약속·책임 인정·보상·효능·배송일 확약은 승인 필수다.
- 사료/간식은 제조원·유통기한(기본 6개월 이상)·성분·원산지·보관·알레르기 정보를 표시한다. 효능 표현은 자동삭제보다 작성·광고 경고를 우선한다.

## AI·토큰·외부 자동화
- 각 사업자 마스터가 자신의 OpenAI API key를 등록하는 BYOK다. 키는 KMS/secret store로 암호화하고 재표시·관리자 복호화를 금지한다. 분실 시 이메일 확인 후 저장키 삭제 및 사용자 재등록만 가능하다.
- 키 오류/예산초과 시 AI 상품조사·콘텐츠·가격/발주 판단은 중단하지만 결정론적 주문·재고 수집, 승인, 안전조치, 알림은 계속한다.
- 사업자별 일/월 AI 예산, 모델(절약/균형/고품질), 생성회수와 관리자 실행 횟수를 설정한다. 변경분만 전달, 구조화 요약/캐시/저가 분류/고난도 승격/토큰 및 tool-call 상한을 적용한다.
- n8n은 핵심 상태/거래 엔진이 아니다. 알림·예약·외부 SaaS 연결용 선택 어댑터이며 없어도 시스템이 동작해야 한다. 외부 고객 제공에 따른 fair-code 라이선스 위험을 ADR로 기록한다.

## 클라우드·앱·개발
- Google Cloud 서울 리전 우선. Cloud Run 등 scale-to-zero, PostgreSQL, 객체저장소, Secret Manager/KMS, FCM, 이메일, scheduler/queue/outbox를 비용과 내구성 기준으로 결정한다.
- 목표비용 월 3천원 수준, 최대 3만원. 2.4만원 경고, 3만원 시 비필수 이미지/영상/조사 중단. 핵심 주문·안전 기능 유지. OpenAI 비용은 BYOK로 별도다.
- Android 우선 설치형 PWA와 동일 반응형 웹. iOS/네이티브는 파이프라인만 둔다. 한국어·영어 UI, 해외 단계에서 아랍어 등 확장한다.
- 앱 핵심 화면: 요약, 분리된 승인함, 주문/발주, 상품, CS, 자금/정산, 공급처, 채널, AI/자동화 설정, 긴급정지/복구, 사용자/권한, 감사기록, 시나리오 테스트.
- ChatGPT는 조회·상품검색·재분석·긴급정지 요청용이며 승인/결제는 모바일 승인화면으로 연결한다.
- 긴급정지는 전체/사업자/채널/공급처/상품 단위. 진행 중 배송/CS는 유지하고 신규 등록·변경·발주를 멈춘다. 복구는 점검 후 한 명 승인, 전체/부분 복구, 중단 작업 선택 재개다.
- GitHub 공개 저장소 `100meAiStore`, 초기에는 라이선스 없음. 코드 전체는 공개하되 실제 키·PII·사업자문서·계약·운영데이터는 개발 첫날부터 저장 금지하고 비공개 클라우드에만 둔다.
- DEMO/LIVE 배지를 표시한다. LIVE는 사업자정보+채널인증으로 가능하지만 공급처가 없으면 상품등록만 허용하고 발주는 차단한다.
- 모의 시스템은 주문, 품절, 원가급등, 배송지연, 환불, API 장애 및 재시작 복구를 재현한다.
- 구현 순서는 아키텍처 확정 후 수직 슬라이스로 진행한다. 완료 기준은 실제 사용 가능하고 장애/재시작 뒤 상태가 복구되는 것이다.

## 아키텍처 산출물 요구
1. 시스템 컨텍스트, 컨테이너/컴포넌트, 배포 토폴로지
2. 멀티테넌트 데이터 모델 및 데이터 소유권/보존
3. RBAC와 승인 정책 매트릭스
4. 상품-등록-주문-발주-배송-클레임-정산 상태기계와 보상 흐름
5. 스마트스토어/쿠팡/공급처/금융/알림/ChatGPT/n8n 어댑터 계약
6. 관리자·전문 에이전트 경계, tool gateway, BYOK, 토큰 예산과 질문 프로토콜
7. Android PWA UX 정보구조와 핵심 승인 화면 계약
8. 보안·개인정보·감사·위협모델과 긴급정지/복구
9. GCP 월 3만원 상한 비용설계, 관측성, 백업/DR
10. DEMO/LIVE 검증전략, 테스트 시나리오, SLO와 출시 게이트
11. ADR 목록, 열린 위험, 구현 backlog/의존성/수용기준
